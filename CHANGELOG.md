# Changelog

## 1.1.0

- New actions: Convert Image to PDF, Convert HEIC to PDF, Convert HEIC to JPG, Convert EPUB to PDF, Extract Pages From PDF, Rotate PDF, Add Page Numbers to PDF, Add Watermark to PDF, Protect PDF With Password, Unlock PDF and Convert PDF to Images: every conv2pdf API tool is now available in Zapier.
- Convert Office Document to PDF also converts Apple Pages documents.
- A refused file or field gets its own message, which names the right action when the file belongs to another one.

## 1.0.0

- First version: Convert Office Document to PDF, Merge PDFs, Compress PDF and Convert PDF to Word.
